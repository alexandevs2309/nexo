# Sistema de tipos — decisión pendiente
Alternativas a comparar: tipado estático/dinámico/mixto; inferencia; tipos nominales/estructurales; genéricos; tipos algebraicos; nulabilidad; mutabilidad; conversiones; subtipado/interfaces; efectos.

Criterios: seguridad, aprendizaje, expresividad, complejidad de implementación, calidad de diagnósticos, interoperabilidad, rendimiento y compatibilidad.

No declarar un sistema definitivo hasta prototipar alternativas y probar casos representativos.
