# Carta del proyecto BASILISCO

> **Nota de integración (este repositorio):** `DEVELOPMENT_STATE.md` y `ROADMAP_MASTER.md` son fuentes de verdad para la fase autorizada/estado/evidencias del roadmap secuencial. Este documento complementa la gobernanza de tareas/registros y debe mantenerse coherente con ellos. No asumir estados "UNKNOWN" como estado real sin contrastar con el repositorio.

## Propósito
Desarrollar BASILISCO como lenguaje coherente, verificable, documentado y mantenible.

## Prioridad
Consolidar lo existente antes de ampliar funcionalidades. La calidad se mide por comportamiento correcto y reproducible, no por líneas de código o tareas iniciadas.

## Principios
1. Correctitud antes que amplitud.
2. Consolidación antes que expansión.
3. Evidencia antes que declaraciones.
4. Una tarea y una fase activas.
5. No avanzar de fase sin aprobación humana.
6. Preservar cambios locales.
7. Registrar discrepancias entre código, pruebas y documentación.

## Autoridad humana exclusiva
El responsable autoriza inicio/cierre de fases, cambios de prioridad/alcance, excepciones, commits, push, merges, releases, publicaciones, cambios a `DEVELOPMENT_STATE.md` e inicio de Fase 04.3 o Fase 05.

## Fuentes de verdad
Código, pruebas, documentación, Git y decisiones del responsable se contrastan entre sí. Ninguna fuente aislada basta. Ante discrepancias, registrar y solicitar decisión.

Este sistema se dedica a BASILISCO. No desviar trabajo a otros proyectos salvo solicitud explícita.
