# CLI, IDE y paquetes
## CLI candidata
Inicializar proyecto, analizar, ejecutar/compilar, probar, formatear, revisar estilo, gestionar dependencias y generar documentación. Nombres finales pendientes.

Requisitos: ayuda en español, códigos de salida documentados, salida estructurada para herramientas y no sobrescribir archivos inesperadamente.

## IDE
Autocompletado, diagnósticos, ir a definición, referencias, renombrado, formateo, depuración, cobertura y perfiles.

## Paquetes
Definir registro, versiones, lockfile, hashes, espacios de nombres, auditoría, propiedad, paquetes abandonados y scripts de instalación. No ejecutar código arbitrario inesperadamente al instalar.
