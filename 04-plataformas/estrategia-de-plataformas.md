# Estrategia de plataformas
Dominios candidatos: CLI/automatización, web/API, web cliente, escritorio, móvil, datos, IA, videojuegos/gráficos y sistemas/bajo nivel.

Para cada dominio documentar casos prioritarios, APIs, distribución, seguridad, rendimiento, dependencias nativas, compatibilidad, pruebas y mantenimiento.

El lenguaje central no promete soporte idéntico para todas las plataformas desde el primer día.
