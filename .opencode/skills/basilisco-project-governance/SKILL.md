# Basilisco Project Governance

Read root AGENTS.md and governance docs first. Inspect Git state before edits. Confirm main; never create branches. Identify one authorized task and one active phase. Put new ideas in BACKLOG.md and unrelated defects in ISSUES.md. Never start a later phase without explicit human approval. Distinguish implemented, verified, and closed. Update records with evidence. No destructive Git commands, commits, pushes, publications, or protected document changes without authorization.

Always follow root `AGENTS.md`. Work only within the explicitly authorized task and stop before any phase transition.
