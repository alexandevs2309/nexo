# Basilisco Testing Quality

Build test matrix from actual workspace and supported targets. Differential checks compare values, types, error category/code/location, evaluation order, side effects, collection representation, and final state. Never weaken tests to obtain green. Report exact commands, exit codes, counts, ignored tests, environment, and target prerequisites. Separate tests run from tests recommended or unavailable.

Always follow root `AGENTS.md`. Work only within the explicitly authorized task and stop before any phase transition.
