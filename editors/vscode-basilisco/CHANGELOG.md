# Changelog

## 0.4.0 (local, no publicado)
- Reconciliación con identidad publicada `alexandevs.basilisco`.
- Se restaura `basilisco.executable` como configuración pública; `basilisco.path` queda como alias legado de compatibilidad.
- Integración LSP real (diagnósticos, completion, hover, definición, referencias, símbolos) vía `basilisco lsp`.
- Integración DAP real vía `basilisco dap` (`bas-dap`).
- Formateo de documento mediante `basilisco formatear`.
- Comandos: Ejecutar archivo, Analizar archivo, Formatear archivo.
- Snippets básicos de Basilisco.
- Gramática/language-configuration corregidas para comentarios `#` y sintaxis Basilisco.
- Pruebas Extension Host automatizadas.

## 0.3.1 (publicado en Marketplace)
- Versión de referencia publicada. Funcionalidades: resaltado, diagnósticos CLI, autocompletado, hover, navegación local, referencias, renombrado, Signature Help, formateador, folding, snippets y comandos.
